title: 8 - Importing Assets
---
*For this demonstration I'll be using a set of basic primitive models and simple textures.*  
*You can download the resource pack [here](/UnrealEngine/assets/Resources.zip)*
## Models

1. In the content drawer, go to \Art\ and create a new folder called **Basics**  
2. Find your assets in the File Explorer.  
3. Select all of them and drag them into the content drawer.  
![[Importing1.png]]

4. When the FBX Importer menu shows, uncheck **Import Materials**
	- *it is always better to build the Material yourself*  
5. Then hit import.  
![[Importing2.png]]

6. You can test your meshes by dragging them from the content drawer into your level.
## Textures

1. In the content drawer, go to \Art\ and create a folder called Textures
2. Find your textures in the File Explorer
3. Select all of them and drag them into the content drawer. Done!
4. To use textures you will need to know how to make materials - the next lesson.
