---
title: 2 - Creating a new Project
---
For full comprehensive instructions please see [here.](https://dev.epicgames.com/documentation/unreal-engine/create-your-first-project-in-unreal-engine?lang=en-US)

After installing and opening Unreal Engine, you are brought to the Unreal Project Browser Window.

The project browser is divided into the following sections:
![](https://dev.epicgames.com/community/api/documentation/image/7158dc6a-ed8b-4968-bc3c-2724ab42b1e1?resizing_type=fit)

| **Number** | **Name**                                | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1          | Recent Projects and Template Categories | This is a list of categories to filter through the available templates.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| 2          | Templates for the selected Category     | This is a list of templates available in a selected category                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| 3          | Project Defaults                        | - **Blueprints or C++** can be used to create a project using Blueprints Scripting or C++. This does not lock you into one or another.<br><br>- **Target Platform** can be used to select a platform you want to build your project for.<br><br>- **Quality Preset** can be used to select the projects visual fidelity. **Maximum** turns on high-end features. **Scalable** balances for performance. Settings can be toggled after the project is created.<br><br>- **Starter Content** includes an additional content pack containing simple meshes with materials and textures. |
1. Choose which settings you like and click **Create**

2. Once Unreal Engine opens the project you will see the **Unreal Engine Level Editor** opened on the default template level.

3. You can navigate the level by holding down the **right mouse button (RMB)**, and using the **W**, **A**, **S**, and **D** keys.
