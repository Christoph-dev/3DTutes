title: 5 - Small Landscape

1. Go to Landscape Mode
![](https://dev.epicgames.com/community/api/documentation/image/9d2f4203-4d1c-40bd-8398-fa6c8f61a4df?resizing_type=fit)

2.
- Set scale to 25
- Set Section Size to 31x31
- Create
![[CreateLandscape.png]]

3. Sculpt Your Landscape
![](https://dev.epicgames.com/community/api/documentation/image/9c866680-2cd7-4e72-9082-85487070dad1?resizing_type=fit)

| Control                   | Operation                   |
| ------------------------- | --------------------------- |
| Left Mouse Button         | Performs Additive Effect    |
| Left Mouse Button + Shift | Performs Subtractive Effect |
| Ctrl + Z                  | Undo                        |
| Ctrl + Y                  | Redo                        |
Use the Sculpting tools to modify the shape of your landscape in various ways.
